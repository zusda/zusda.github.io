从零开始的LLM 13.LLM模型及训练

发表于 2026-09-14 更新于 2026-09-16

前言

在 2.LLM模型及训练 中，我曾介绍过 Transformer 的三类主要架构。不过当时刚开始系统学习 LLM，关注点主要集中在 Decoder 结构，对 Encoder 和 Encoder-Decoder 的理解还不够深入。

最近在学习记忆压缩相关方法时，需要重新梳理 Encoder 和 Encoder-Decoder 架构，也因此发现了之前文章中一些理解上的疏漏。因此，这次重新整理并撰写这篇文章，对decoder简单介绍，着重于其他两种结构。

1. Transformer

1.1 Transformer 是什么

Transformer 是一种神经网络模型架构。我们在前文推导的 Multi-Head Attention，正是 Transformer 最核心的组成部分。一个完整的 Transformer 由 Encoder（编码器）或 Decoder（解码器），以及若干归一化层与线性层共同构成。

目前主流的 Transformer 模型分为三类：

  • Encoder-Only：只理解，不生成（代表：BERT）
  • Decoder-Only：以生成为核心（代表：GPT、Claude）
  • Encoder-Decoder：理解后再生成（代表：T5、翻译模型）

2. Encoder-Only

在 Encoder-Only 架构中，Attentioni部分只由 Self-Attention 组成。

如图所示，一个 Encoder Layer 通常由两个子结构串联组成：

  1. Self-Attention：输入首先经过 Self-Attention，让每个 token 根据其他 token 的信息更新自身的表示，然后通过残差连接（Residual Connection）与原始输入相加。

  2. FFN（Feed-Forward Network）：上一步得到的结果进入前馈网络进行进一步的非线性变换，再通过残差连接与输入相加。FFN 不会让不同 token 之间发生信息交互，而是独立地处理每个 token。经过 FFN 后，token 的数量不变，最终通过残差连接与 FFN 的输入相加。

为什么需要Attention 与 FFN 的分工？

Attention 和 FFN 在 Transformer 中承担着不同的作用。

  1. Attention 的核心作用是信息交互。 Self-Attention 会根据 Query 和 Key 计算不同 token 之间的注意力权重，再对 Value 进行加权求和。因此，它解决的主要问题是：当前 token 应该从其他 token 获取哪些信息，以及获取多少信息。 但 Attention 本身并不能单独完成足够复杂的非线性特征变换。

  2. FFN 的核心作用是对每个 token 的表示进行非线性变换。 它对 Attention 混合后的信息进行进一步加工，通过非线性激活函数增强模型的特征表达能力，帮助模型学习更加复杂的语法、结构和语义关系。

两者不断交替，使 Transformer 能够逐层构建更加复杂的语义表示。

2.1 预训练任务 —— MLM

BERT 主要采用 MLM（Masked Language Model，掩码语言模型）进行预训练。

MLM 可以理解为一种“完形填空”任务：在文本序列中随机选择一部分 token，将其遮蔽，然后要求模型根据上下文预测这些位置原本是什么 token。

其中，[MASK] 是 BERT 词表中专门添加的特殊 token，与 [CLS]、[SEP]、[PAD] 等一样，都具有固定的 token ID。

需要注意的是，并不是所有位置都参与损失计算。只有被选中的 Mask 位置，其输出才会被送入分类层，并与对应的真实 token 计算交叉熵损失：

模型实际上会为每个位置输出一个该位置的整个词表上的概率分布**，然后使用真实 token 对应的概率计算交叉熵。

Decoder-Only（如 GPT）的预训练方式不同。

Decoder-Only 通常使用 CLM（Causal Language Modeling，因果语言模型）。模型在每个位置预测下一个 token，并通过 Causal Mask 阻止当前位置看到未来 token。

在具体训练时，BERT 随机选择每条训练语料中 15% 的 token 参与预测，但这 15% 并非全部替换为 [MASK]，而是按如下比例处理：

处理方式 概率 目的
替换为 [MASK] 80% 核心遮蔽，驱动模型预测
替换为随机 token 10% 迫使模型保持对全部 token 的上下文表征
保持原 token 不变 10% 消除预训练与微调阶段的分布偏移

2.2 预训练任务 —— NSP

MLM 主要学习 token 级别的上下文关系，但一些 NLP 任务还需要理解句子之间的关系。

例如：

  • 问答匹配：判断问题与回答是否匹配；
  • 自然语言推理（NLI）：判断一个假设是否能够由前提推出；
  • 句子关系判断：判断两个句子之间是否存在特定关系。

因此，BERT 在原始论文中还引入了 NSP（Next Sentence Prediction，下一句预测）任务。

NSP 的任务非常简单：给模型两个句子，让模型判断第二个句子是否是原始文本中紧接着第一个句子的下一句。

例如：

如果 B 确实是原文中 A 的下一句，则标签为：IsNext，否则：NotNext

本质上，这就是一个带标签的二分类任务。

BERT 使用 [CLS] 位置的最终隐层向量作为整个句对的表示，然后接入一个分类层。

可以简单理解为：NSP 是在 BERT 的 Encoder 输出基础之上增加一个分类任务，通过监督学习训练模型判断两个句子之间的关系。

3. Decoder-Only

Decoder-Only 模型的 Attention 部分只使用 Masked Self-Attention。

Masked Self-Attention：每个 token 只能关注自己以及它之前的 token，无法看到后续位置的 token。这保证了自回归生成时的信息约束——模型在预测第 (i) 个 token 时，不能“偷看”第 (i+1) 个及之后的内容。

与 Encoder-Only 模型类似，Decoder Layer 在 Attention 后同样包含 FFN（通常在现代 LLM 中称为 MLP），用于对 Attention 混合后的信息进行进一步的非线性变换。

3.1 预训练任务 —— CLM

Decoder-Only 模型（如 GPT）通常采用 CLM（Causal Language Modeling，因果语言模型）进行预训练。

CLM 的核心思路是：

给定前面的所有 token，预测下一个 token。

由于使用了 Masked Self-Attention，模型在训练时无法看到当前 token 后面的内容，因此只能根据前文进行预测。

3.2 SFT（Supervised Fine-Tuning，有监督微调）

经过预训练后，LLM 已经具备较强的语言建模能力，但此时模型学习到的主要是根据上下文预测下一个 token，并不意味着它已经很好地掌握了“按照用户指令完成任务”的能力。

因此，通常还需要通过 SFT（Supervised Fine-Tuning，有监督微调）进一步训练模型，使其学习指令遵循、问答、翻译、总结等任务。

与 BERT 等 Encoder-Only 模型的下游任务微调不同，Decoder-Only LLM 通常不会针对每一种任务单独增加一个分类头，而是仍然让模型直接生成文本。

4. encoder-decoder

Encoder-Decoder 架构由 Encoder 和 Decoder 两部分组成。

Encoder：

每层包含 Self-Attention 和 FFN。由于没有因果掩码，Encoder 中的每个 token 都可以关注输入序列中的其他 token。

Decoder：

每层包含 Masked Self-Attention、Cross-Attention 和 FFN。

  • Masked Self-Attention：对 Decoder 当前已经生成的序列进行自注意力计算，通过 Causal Mask 屏蔽未来位置，确保生成时不会看到尚未生成的 token。
  • Cross-Attention：Q 来自 Decoder 当前状态，K 和 V 来自 Encoder 的输出，使 Decoder 在生成每个 token 时能够关注 Encoder 输出中的相关信息。

4.1 训练中的前向传播

Encoder-Decoder 模型需要两个输入：Encoder 输入和 Decoder 输入。

Encoder 输入是我们希望模型进行编码的内容，而 Decoder 输入则来自我们希望模型生成的目标内容。

Encoder 首先对输入序列进行 Self-Attention。由于Self-Attention中，每个位置都可以关注整个输入序列，因此 Encoder 的输出包含完整的上下文信息。

随后，Decoder 对目标序列进行处理。训练过程中，Decoder 的输入来自目标序列，但会向右移动一位，使模型在每个位置预测下一个 token。

Decoder 的输入首先经过 Masked Self-Attention，使每个位置只能看到自己以及之前的 token。

然后进入 Cross-Attention：

  • Q 来自 Decoder 当前的隐层表示；
  • K 和 V 来自 Encoder 的输出。

因此，Decoder 的 Masked Self-Attention 输出 在 Cross-Attention 中，可以访问 Encoder 输出中的所有 token 信息。（我们attention原理中说过，图结构是Q连向K的。）

4.2 预训练任务

T5（一个 encoder-decoder 模型）的预训练任务称为 Span Corruption。它与 BERT(encoder-only) 的 MLM 类似，但有一个关键区别：BERT 遮蔽的是单个随机 token，而 T5 遮蔽的是连续的 token 片段（Span）。

预训练的目标，是让 encoder 具备理解能力。但“理解”本身是个抽象概念，怎么定义它、怎么衡量它？

T5 的思路是：借助 decoder 来定义 encoder 的理解能力。如果 decoder 能根据 encoder 的输出，准确还原出被遮蔽的内容，就说明 encoder 真正理解了上下文。

同时，由于 loss 是从 decoder 的输出反向传播回去的，训练过程中也会顺带训练出一个能够解析 encoder 内容的 decoder。

4.3 微调：统一到 Text-to-Text 框架

得益于 Text-to-Text 的统一框架，T5 的微调方式非常一致：无论任务类型是什么，都只需构造对应格式的输入输出文本对，在预训练模型上继续训练即可，无需修改任何模型结构。

预训练和微调的核心差异在于 decoder 的目标：

  • 预训练阶段：decoder 的目标是解释 span 里缺了什么，借此反向定义并训练 encoder 的理解能力。
  • 微调阶段：decoder 的目标回归到正常的答案生成，即根据具体任务要求输出结果。
