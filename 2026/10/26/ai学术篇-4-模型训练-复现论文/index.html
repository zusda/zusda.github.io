前言

本文主要通过复现论文 Pretraining Recurrent Networks without Recurrence 来讲解模型训练的每个步骤。

姑且将 AI 系列后续内容分为以下 4 个部分：

  1. 学术篇： LLM 基础知识、模型训练、各类算法的原理与实现等。
  2. 开发篇： Agent 框架、各类 AI 应用的开发等。
  3. 运维篇： Agent 应用的部署、推理参数测试等。
  4. 杂项： AI 渗透、视频生成、音频生成、超分辨率等其他内容。

之前一直在寻找循环记忆的实现方法，后来找到了这篇论文。虽然它在实现形式上符合我的需求，但其实现原理与我的设计目标并不一致。

不过，通过学习这篇论文，我了解了如何从网络设计入手，逐步完成模型实现、训练和验证的完整流程。此外，论文中的方法也给了我启发，让我开始尝试设计符合自己需求的网络。由于目前缺乏相关经验，我决定先复现原作者的网络，熟悉完整的实现与训练流程，再继续探索自己的设计。

1. Pretraining Recurrent Networks without Recurrence

  • 论文：https://arxiv.org/abs/2606.06479
  • 作者代码：https://github.com/akarshkumar0101/smt

学习方式： 先理解论文原理，再参考作者代码自行重写。在保持超参数不变的前提下，重新组织代码结构，并进行必要的优化。

主要目的： 熟悉完整的模型实现与训练流程，形成一套相对标准化的代码结构，方便后续实现和训练其他网络。

1.1 原理概述

基线：通过 BPTT 训练 RNN

基本做法：

将 RNN 沿时间维度展开，每个时间步根据上一步的记忆和当前输入更新记忆： \[ m_t = f(m_{t-1}, x_t) \] 训练时，通过损失函数计算预测误差，并使用时间反向传播（Backpropagation Through Time，BPTT）计算梯度，更新网络参数。

主要问题：

  1. 时间维度上的计算存在串行依赖。 当前记忆 \(m_t\) 依赖上一时刻的记忆 \(m_{t-1}\)，因此无法直接并行计算所有时间步的记忆状态。
  2. 长距离梯度传播困难。 相距较远的 token 之间，梯度需要经过多个连续的非线性状态更新，容易出现梯度消失或梯度爆炸。
  3. 长程信息利用受到限制。 随着信息传播距离增加，模型更难有效利用较早的上下文，容易表现出近因偏置（Recency Bias），即更倾向于依赖近期信息。

 

 

论文方法：SMT 与 DMT

SMT（Supervised Memory Training）

核心思想： 将「记什么」与「怎么更新记忆」拆开。

  • Teacher： 由 Transformer 的 teacher.encoder 和 teacher.decoder 组成，通过预测未来的训练目标学习记忆表示。

    • teacher.encoder 将过去的上下文窗口压缩为固定大小的记忆 \(Z_t\)。
    • teacher.decoder 根据记忆 \(Z_t\) 和后续 token 学习预测未来。
    • 通过这种方式，记忆表示能够保留对未来预测有用的信息。

  • RNN： 主要训练 rnn.encoder，学习一步记忆转移：

    \[ (Z_t, x_{t+1}) \rightarrow Z_{t+1} \]

    其中，输入记忆 \(Z_t\) 和目标记忆 \(Z_{t+1}\) 均由 teacher.encoder 生成。rnn.encoder 使用均方误差（MSE）拟合目标记忆。

训练优势：

由于各个时间步的目标记忆可以通过 teacher.encoder 独立计算，因此不需要展开 RNN 的递归链，就能构造多个记忆转移训练样本。

这样可以并行计算不同时间步的记忆转移，避免传统 RNN 在前向计算中逐步更新记忆的限制。同时，每个记忆转移任务的梯度只需经过一步更新，不必沿整条递归链反向传播。

DMT（DAgger Memory Training）

为什么需要 DMT？

SMT 训练时，rnn.encoder 接收的是 teacher.encoder 生成的记忆 \(Z_t\)。但在实际推理时，RNN 必须使用自己生成的记忆 \(\hat Z_t\) 作为下一步的输入。

即使输入 token 仍然使用真实数据（Teacher Forcing），记忆预测误差也可能逐步累积，使学生网络生成的记忆偏离 Teacher 的记忆轨迹。

可以使用以下公式衡量两个记忆状态之间的偏差： \[ \delta_t = \mathrm{MSE}(\hat Z_t, Z_t) \] DMT 的做法：

  1. 生成目标记忆轨迹。 使用 teacher.encoder 计算目标记忆序列：

    \[ [Z_0, \ldots, Z_T] \]

  2. 生成学生记忆轨迹。 使用 rnn.encoder 自回归展开，得到自身生成的记忆序列：

    \[ [\hat Z_0, \ldots, \hat Z_T] \]

  3. 训练 rnn.encoder。 将 SMT 阶段的输入记忆 \(Z_t\) 替换为学生网络自身生成的记忆 \(\hat Z_t\)，但仍以 Teacher 生成的 \(Z_{t+1}\) 作为监督目标：

    \[ (\hat Z_t, x_{t+1}) \rightarrow Z_{t+1} \]

    使用 MSE 计算记忆预测损失： \[ \mathrm{MSE}(\hat Z_{t+1}, Z_{t+1}) \] 这样，rnn.encoder 就能学习从自身产生的记忆状态出发，继续逼近 Teacher 的目标记忆。

  4. 训练 rnn.decoder。 使用 rnn.encoder 生成的记忆 \(\hat Z_t\) 预测下一个 token，通过交叉熵损失进行微调： \[ \mathrm{CE}\left(y_t,\mathrm{rnn.decoder}(\hat Z_t)\right) \]

    该损失只更新 rnn.decoder，不向 rnn.encoder 反向传播梯度。因此，需要对输入记忆 \(\hat Z_t\) 使用 detach()，将其从计算图中分离。

冻结与更新情况：

模块 DMT 阶段的状态
teacher.encoder 冻结，只负责生成目标记忆
teacher.decoder 冻结，不参与 DMT 阶段的训练
rnn.encoder 使用 MSE 学习记忆更新，学习率较小
rnn.decoder 使用下一 token 的交叉熵损失进行微调，只更新自身参数

 

 

训练产物

最终得到一个基于固定大小记忆的循环语言模型：输入一个 token，更新一次记忆，再根据记忆预测下一个 token，不需要保存完整的历史 token 序列。

模块 作用 推理时是否需要
teacher.encoder 将上下文窗口编码为记忆，为 rnn.encoder 提供监督目标 不需要
teacher.decoder 在训练阶段参与 Teacher 的预测目标学习 不需要
rnn.encoder 根据当前记忆和输入 token 更新记忆 需要
rnn.decoder 根据记忆预测下一个 token 需要

补充说明：

  • teacher.encoder 生成的每个记忆 \(Z_t\) 都由对应的上下文窗口独立编码得到，不依赖上一个记忆状态。
  • 递归更新关系只存在于 rnn.encoder 中。
  • SMT 和 DMT 训练得到的 rnn.encoder 与 rnn.decoder 才是最终部署的模型。Teacher 负责提供监督信号，其预测效果也可以作为 Student 的性能参照。

 

 

与普通基线（BPTT）的区别

一、核心区别

  • BPTT： RNN 同时学习记忆表示和更新方式，通过递归展开和端到端反向传播进行训练。
  • SMT / DMT： 由 Transformer 学习记忆表示，RNN 学习记忆更新。SMT 进行并行监督训练，DMT 让 RNN 适应自身生成的记忆。

二、关键区别

1. 长程依赖

  • BPTT： 梯度需要经过多个递归步骤，容易消失或爆炸，影响长程信息的学习。
  • SMT： Transformer 通过自注意力提取长程信息并压缩为记忆，RNN 只需学习一步记忆转移。

2. 训练效率

  • BPTT： 需要展开 RNN，训练显存通常随序列长度增加。
  • SMT： 随机采样时间步，独立构造训练样本，无需展开完整的递归链。

论文默认参数：上下文窗口长度 (T_c=256)，未来预测窗口长度 (T_f=64)。

三、容易混淆的两点

  1. DMT 不等于 BPTT。 DMT 虽然需要递归展开，但记忆更新使用逐步 MSE 监督，不需要沿整条递归链反向传播梯度。
  2. 并行优势主要在 SMT 阶段。 DMT 需要自回归展开，仍存在时间上的串行依赖。

四、方法定位

  • SMT： 预训练 RNN，使其学习 Teacher 的记忆更新方式。
  • DMT： 让 RNN 适应自身生成的记忆，减轻误差累积。
  • Teacher： 提供记忆监督信号和性能参照，所以 teacher 的效果也是 rnn 性能的上限参照。。

 

 

1.2 模型设计

代码中使用两个模型：teacher（teacher.encoder + teacher.decoder）和 rnn（rnn.encoder + rnn.decoder）。

teacher 模型

teacher.encoder（压缩）
  • 输入： 固定长度的 token 序列 \(x_1,\dots,x_t\)。
  • 输出： 固定长度的记忆 \(Z_t\)，包含 \(n\) 个记忆 token。

\[ x_1,\dots,x_t \to Z_t,\qquad Z_t=\{m_t^1,m_t^2,m_t^3,m_t^4\}\quad(n=4) \]

teacher.decoder（预测下一个 token）
  • 输入： 记忆 \(Z_t\) 和后续 token 序列 \(x_{fut}\)。
  • 输出： 与 \(x_{fut}\) 等长的预测 logits。
    • 最后一个记忆位置的输出预测 \(x_{fut}\) 的第一个 token。
    • \(x_{fut}\) 中除最后一个位置外，其余位置分别预测各自的下一个 token。

rnn 模型

rnn.encoder（记忆更新）

与 teacher.encoder 压缩整个窗口不同，rnn.encoder 每次只更新一步记忆。

  • 输入： 旧记忆 \(Z_t\) 和新 token \(x_{t+1}\)。
  • 输出： 更新后的记忆预测 \(\hat Z_{t+1}\)。
  • 标签： \(Z_{t+1}=\text{teacher.encoder}(x_1,\dots,x_{t+1})\) 对应的滑动窗口记忆。
  • 损失： \(\mathrm{MSE}(\hat Z_{t+1},Z_{t+1})\)。

\[ (Z_t,x_{t+1})\xrightarrow{\text{rnn.encoder}}\hat Z_{t+1} \]

rnn.decoder（预测下一个 token）
  • 输入： 记忆 \(Z\)，推理时使用 rnn.encoder 生成的记忆。
  • 输出： 预测记忆之后的下一个 token。

 

 

1.3 SMT 流程

SMT 的一次前向计算分为四步：切分 batch、生成 teacher 记忆、计算未来预测损失、计算 RNN 记忆更新损失。

1. 数据准备

以 \(T_c=4\)、\(T_f=4\) 为例，从 batch 中切出四份数据：

变量 切片 内容 用途
x_ctx x[:, :Tc] \([x_0,x_1,x_2,x_3]\) 输入 teacher.encoder，得到 \(Z_t\)
x_fut x[:, Tc:Tc+Tf] \([x_4,x_5,x_6,x_7]\) 输入 teacher.decoder
y_fut y[:, Tc-1:Tc+Tf-1] \([y_3,y_4,y_5,y_6]\) teacher.decoder 的预测目标
x_ctx_next x[:, 1:Tc+1] \([x_1,x_2,x_3,x_4]\) 输入 teacher.encoder，得到 \(Z_{t+1}\)

其中，y_fut 与 decoder 的输出位置对齐。例如，位置 3 的输出预测 \(x_4\)，其目标为 \(y_3=x_4\)。

为什么 \(Z_{t+1}\) 不是对 \([x_0,x_1,x_2,x_3,x_4]\) 进行压缩？

因为 teacher.encoder 每次只接收固定长度 \(T_c\) 的窗口。窗口向前移动一个 token 后，输入变为 \([x_1,\dots,x_4]\)，因此得到 \(Z_{t+1}\)。

这意味着每个记忆都由当前窗口独立编码，teacher 生成的记忆之间没有递推关系。

因此，RNN 学到的记忆更新能力受 teacher.encoder 生成的记忆表示限制。对于已经填满窗口的序列，新记忆会丢弃窗口中最早的 token 对应的信息；只有窗口尚未填满时，才能逐步累积输入内容。

2. 前向计算

x_in 取 x_fut 的第一个 token \(x_4\)，正好是 x_ctx_next 相比 x_ctx 新增的 token。因此，RNN 的输入 \((Z_t,x_4)\) 与目标记忆 \(Z_{t+1}\) 对齐。

3. 反向更新路径

损失 作用 更新的网络
loss_decoder 使记忆能够用于预测未来 teacher.encoder、teacher.decoder
loss_rnn 使 RNN 的一步更新逼近 teacher 的下一份记忆 rnn.encoder、teacher.encoder

4. 为什么 loss_rnn 也要更新 teacher.encoder？

这是联合优化设计：teacher.encoder 不仅要生成适合预测未来的记忆，还要生成便于 rnn.encoder 一步更新得到的记忆。

如果冻结 teacher.encoder，RNN 只能拟合固定的记忆表示。当这个表示不利于预测局部状态转移时，RNN 就难以学好。

联合训练允许双方相互配合：teacher.encoder 调整记忆表示，使其更适合预测状态转移；rnn.encoder 学习相应的更新规律。

但联合训练也有三个问题：

  1. 目标冲突： teacher.encoder 同时追求信息保留和状态转移的可预测性，可能难以兼顾。
  2. 隐空间坍缩： teacher.encoder 将不同输入映射到同一个常数，rnn.encoder 也输出相同常数，导致 MSE 接近零，但记忆丢失了输入信息。
  3. 训练不稳定： teacher.encoder 持续更新，导致 rnn.encoder 的监督目标不断变化。

解决办法：加权损失与均匀性损失。

  • 主任务（权重 1.0）： teacher.encoder 压缩输入，teacher.decoder 预测未来序列，促使记忆保留预测所需的信息。
  • 辅助任务（权重 0.1）： rnn.encoder 预测下一时刻的记忆，使记忆表示更适合状态转移。
  • 均匀性损失（权重 0.001）： 惩罚 batch 内不同样本的记忆过于接近，降低隐空间坍缩的风险。

主任务为主、辅助任务为辅，可以减轻目标冲突；均匀性损失则进一步抑制记忆坍缩。辅助损失权重过小会使 RNN 学习不足，而仅依赖主任务也不能彻底避免坍缩。

最终损失为： \[ \mathcal{L} = 1.0\cdot\text{loss\_decoder} + 0.1\cdot\text{loss\_rnn} + 0.001\cdot\text{loss\_unif} \]

5. 两个训练目标的作用

目标一：训练 teacher.encoder，使记忆包含能预测 x_fut 的信息

目标二：训练 rnn.encoder，使它学会 \(Z_{t+1} = \text{rnn.encoder}(Z_t, x_{t+1})\)

 

 

1.4 DMT 流程

DMT 分为三步：先用 teacher.encoder 生成标准记忆轨迹，再让 RNN 自主滚动生成记忆轨迹，最后计算两者的差异。

与 SMT 不同，DMT 只更新 rnn.encoder 和 rnn.decoder，teacher 只提供监督目标。

代码方法与内部网络的对应关系如下：

代码方法 内部网络 作用
teacher.encode(x_ctx) teacher.encoder 将窗口压缩成记忆 \(Z\)
teacher.decode(z, x_fut) teacher.decoder 根据记忆和后续 token 预测未来
rnn.rnn_update(z, x) rnn.encoder 更新记忆：\((Z_t,x_{t+1})\to\hat Z_{t+1}\)
rnn.rnn_readout(z) rnn.decoder 读取记忆，预测下一个 token

第一段循环：生成 teacher 记忆轨迹

range(0, cfg.Td, cfg.k) 表示从 0 开始，每隔 k 步取一个时间步，用于控制 teacher.encoder 的计算频率。

将列表堆叠为张量

torch.stack 会沿新增维度堆叠形状相同的张量。每个 z 的形状为 (B, n, D)，共 Td 个：

这里使用 dim=1，使 batch 维保持在最前面，时间维排在第二位。

第二段循环：让 RNN 自主滚动
  • 初始记忆： 取自 teacher.encoder；后续记忆由 rnn.encoder 自己生成。
  • 新 token： 使用真实序列中的 token，相当于 teacher forcing；只有记忆状态由 RNN 自己递推。
  • **z_t.detach()**： 切断读出损失到记忆生成过程的梯度路径，使该损失只训练 rnn.decoder，不通过读出分支更新 rnn.encoder。
比较两条记忆轨迹

loss_dyn_ 使用 MSE 衡量 RNN 自主生成的记忆轨迹 z_rnn 与 teacher 生成的标准轨迹 z_enc 之间的差异。

2. 反向传播

损失 作用 更新的网络
loss_readout 使 rnn.decoder 能根据 RNN 生成的记忆预测下一个 token rnn.decoder
loss_dyn_ 使 RNN 生成的记忆轨迹接近 teacher 的轨迹 rnn.encoder

teacher 的参数不加入优化器，因此不会被更新。实现时可以使用 torch.no_grad() 执行 teacher 前向计算，以节省显存。

3. 两个训练目标

目标一：训练 rnn.decoder，使其能根据当前记忆预测下一个 token。

输入是 RNN 自己生成的记忆，且已执行 detach()，因此 rnn.decoder 学习的是如何读取这些记忆，包括递推过程中产生的偏差。

目标二：训练 rnn.encoder，使其生成的记忆轨迹接近 teacher。

teacher 生成的记忆作为监督目标，不更新 teacher 参数；rnn.encoder 则通过轨迹损失学习记忆更新规律。

2.2 模型构造

2.2.1 预备知识

写模型代码前，先了解四个概念：Embedding 层、记忆槽的初始向量、网络层数、记忆向量归一化。

1. Embedding 层

两个参数：

  • vocab_size：词表大小，即 token 种类数，token ID 范围是 0 ~ vocab_size-1。
  • d_model：每个 token 对应向量的维度。
  • 两者相互独立，可以不同，也可以相等。

原理：

  • Embedding 内部是一张形状为 (vocab_size, d_model) 的可学习矩阵，每一行对应一个 token ID。
  • 输入 token ID 相当于按行号查表，直接取出对应向量。
  • 数学上等价于 one-hot 向量乘权重矩阵，但实际直接查表，不需要构造 one-hot 向量。

示例： vocab_size=4、d_model=3 时，Embedding 内部是 4 行 3 列的矩阵。输入 [2, 0]，就取出第 2 行和第 0 行，输出形状为 (2, 3)。

Embedding 中的向量如何学习：

  • 初始化时，矩阵中的数值通常是随机的。
  • 训练时，参与计算的 token 对应的向量会根据梯度更新；没有参与计算的 token，对应行不会因这次计算而更新。
  • 训练结束后，向量固定下来，不同 token 的表示反映模型从训练数据中学到的特征。

字节级模型：

  • 本文使用的 token 是字节（0–255），而不是字或词，因此词表大小固定为 256。
  • 一个常用汉字在 UTF-8 编码下通常占 3 个字节，对应 3 个 token，也就是 3 个向量。
  • 生成时每一步输出一个 token ID，需要连续生成相应字节，再解码为文本。
  • 这种方式可以覆盖任意文本，但通常会产生比子词分词更长的序列。
2. 为什么记忆槽的初始向量设为可学习参数？

在 teacher.encode(x_ctx) 中，拼接到输入序列末尾的 K 个记忆槽，初始时并不包含输入文本的信息。它们的作用是通过注意力读取上下文，并把信息编码到自身的输出向量中。

  • 固定使用彼此不同的随机向量也可以工作，Encoder 的参数会适应这些初始向量。
  • 设为可学习参数，可以让模型自行调整每个槽位的初始表示，几乎不增加参数量。
  • 类似设计也常见于 [CLS]、Perceiver 的 latents 和 Q-Former 的 queries。

使用 RoPE 时，不同位置还会产生相对位置差异，但这并不意味着相同的初始向量一定能充分区分不同槽位。因此，不建议把所有记忆槽初始化为同一个常量。

3. encoder、decoder 的层数

结论：增加层数意味着增加信息加工的轮数，而不是直接增加模型能看到的信息量。

decoder 加深的作用： 单层 Decoder 就能访问当前位置之前的全部 token。加深不是让模型看到更多前文，而是增加信息加工的轮数。

  • 每一层都会基于上一层的输出继续计算，通过自注意力进行上下文交互，再通过 FFN 进行非线性变换。
  • 层数增加后，token 表示可以经过更多轮交互与变换，从而学习更复杂的上下文特征。
  • 浅层、中层、深层可能形成不同程度的特征组合，但具体学到什么取决于训练过程，并非每层都有固定职责。

encoder 加深的作用： Encoder 加深，不是增加积木，而是让有限的积木经过更多轮加工与组合，有机会表达更复杂的意义。

  • 每一层都会更新输入序列中各位置的表示。
  • 即使最终只保留 K 个记忆槽的输出，这些槽位也可以通过自注意力与整个输入窗口交互。
  • 可以把最终保留的 K 个向量理解为内部数量有限的积木：增加 encoder 层数，就是让这些积木经过更多轮加工与组合，以表达更丰富的输入特征。
4. 记忆向量归一化（normalize_mem）

作用： 对每个记忆向量独立做 RMS 归一化，把均方根调整为 1。对于 D 维向量，归一化后向量长度为 D，主要保留方向信息。

对记忆表示的影响：

  • 各记忆向量的整体数值尺度被固定，模型不能再通过向量长度直接表达信息。
  • 如果不同记忆槽主要负责相对独立的内容，例如一个存储时间、另一个存储物品名称，固定长度不会造成明显损失。
  • 如果某些关系依赖向量大小或不同向量之间的尺度差异，归一化会限制这种表达方式。不过，方向仍然可以编码关系，因此不能据此断言相关信息一定丢失。

本文严格按照论文代码的设计，全程启用记忆归一化。

一种可选策略：

  • 训练初期启用归一化，先稳定记忆向量的尺度；之后逐步减弱归一化，让模型自行决定是否利用向量大小表达信息。
  • 直接关闭归一化会改变下游接收到的输入分布，可以通过渐变方式过渡：

\[ z=(1-\alpha)\cdot\operatorname{normalize}(z)+\alpha\cdot z \]

其中，α 在若干训练步内从 0 逐渐增加到 1。

2.3.2 数据预处理与 Batch 构建

数据预处理要解决两个问题：如何保存和读取数据（数据准备），以及如何从数据中构建训练所需的 Batch（采样 Batch 的函数）。

常见做法有两种：自定义 sample_batch() 函数，或使用 Dataset + DataLoader。两者并不互斥，选择哪一种主要取决于数据的组织形式和采样方式。

使用 Dataset + DataLoader 时，构建 Batch 的工作变成只需要实现 Dataset 类的 __getitem__(idx) 函数，采出一个样本；后续由 DataLoader 负责组成 Batch。

方案一：连续数据与 sample_batch()

适用于需要从连续序列中随机截取片段的场景，例如语言模型训练中的 token 序列。

  1. 预处理： 将数据编码后保存为一维 NumPy 数组。
  2. 训练时采样： 随机生成起始位置，从长数组中截取所需长度的片段，再组成形状为 (batch_size, seq_len) 的 Tensor。

这种方式把采样和 Batch 构建集中在一个函数中，适合连续数据。

方案二：独立样本与 Dataset + DataLoader

适用于样本之间相对独立的数据，例如图片分类或指令微调数据。

  1. 预处理： 将数据整理成多条独立样本。
  2. 实现 Dataset 类：
    • len()：返回样本总数。
    • getitem(idx)：根据索引返回一条样本。
  3. 构建 Batch： 使用 DataLoader 采样和组织数据。若样本形状或长度不一致，可通过 collate_fn 进行 padding、拼接等处理。

连续数据也可以封装进 Dataset，因此两种方案在能力上并不互斥。

如何选择
数据形态 推荐方式 原因
一组相互独立的样本 Dataset + DataLoader 接口规范，Batch 组织和加工较方便
从连续数据中动态截取片段并组成 Batch 自定义 sample_batch() 采样和加工逻辑集中，代码更直接

对于本次 TinyStories 实验，需要从拼接后的长序列中随机截取训练片段，因此使用自定义 sample_batch() 更直观。

2.3.4 Tokenizer 准备

本次实验使用的 TinyStoriesTokenizer 是一个非常简单的 ASCII 编码器，并不是常见的 BPE、WordPiece 等子词分词器。

它将字符串编码为 ASCII 字节序列，再将每个字节值作为 token ID。vocab_size 设置为 256，但标准 ASCII 字符只占用 0–127；由于代码使用 errors="ignore"，无法用 ASCII 编码的字符会被忽略。

例如：

  • 'H' → 72
  • 'i' → 105
  • 空格 → 32

这一步只完成从文本到整数 ID 的转换。模型后续可以通过 Embedding 层将每个 ID 映射为向量；向量维度由模型的 embedding 配置决定，不一定是 256。

数据准备的最后一步，是实现从长序列中随机采样训练 Batch 的函数。

采样时，每个随机起点都会截取 batch 个 sample_len + 1 个 token。随后：

  • batch[:, 1:]：去掉第一个 token，作为目标 y。

这样，输入与目标的长度相同，且目标序列相对于输入序列向右错开一个位置，实现下一个 token 预测。

  2. 每 10 步在 test 集上算一次 loss，作为实际效果检测
  3. 设置学习率（固定学习率的话可去掉）
  4. 前向传播算 loss、反向传播算梯度
  5. 裁剪梯度、更新参数

要点：

  • clip_grad_norm_ 返回裁剪前的范数，所以日志里记录的是真实的梯度大小，可以用来监控训练是否稳定。.item() 把张量转成普通数字，才能写进 json。
  • rnn.decoder 没有梯度（为 None），clip_grad_norm_ 会自动忽略这些参数。
  • 评测放在参数更新之前，所以第 itr 步记录的 test loss 反映的是更新前的模型。

2.4.6 fw_bw_loss_calculation：前向与反向

前向算 loss、反向算梯度是标准化步骤，统一放在一个函数里。test 分支只前向，不反向。

o 是什么： forward_smt 返回的字典，含四项标量 loss（loss_decoder、loss_rnn_enc、loss_unif、loss），所以 numel()==1 的过滤会把它们全部保留。

2.4.7 forward_smt：SMT 专属的前向

前向和具体模型怎么操作有关，所以单独实现，最终目标是返回 loss。原理在 1.3 已讲过，这里不再逐步说明，细节看注释。

梯度的去向（与 1.3 一致）：

  • loss_decoder 的梯度流向 teacher.decoder 和 teacher.encoder；
  • loss_unif 只作用于 z_now，流向 teacher.encoder；
  • loss_rnn_enc 的梯度流向 rnn.encoder（含 rnn.embed），同时也流向 teacher.encoder，因为 z_now 和 z_next 都由 teacher.encode 产生，代码里没有 detach。

2.5 DMT 训练部分

DMT 训练的代码结构和 2.3 的 SMT 完全一样：main → 训练类 → run → step → fw_bw_loss_calculation → 前向函数。区别集中在下面几处，原理前文已讲，这里只讲代码上的不同。

2.5.1 与 SMT 的差异一览

  • 训练对象不同：
    • SMT：teacher 和 rnn 一起训练。
    • DMT：先加载 SMT 的结果，teacher 冻结，只训练 rnn（rnn.encoder 和 rnn.decoder 都训练）。
  • 优化器和梯度裁剪： 只处理 rnn.parameters()，teacher 的参数不进优化器。
  • 损失不同：
    • SMT：teacher.decoder 的交叉熵 + rnn.encoder 的 MSE + 均匀性损失。
    • DMT：rnn.decoder 的读出交叉熵 + rnn 自己展开的轨迹与 teacher.encoder 标准轨迹的 MSE + 均匀性损失（这一项实际只是监控指标，见文末说明）。
    • teacher.decoder 的损失在 DMT 里整个删掉。
  • 前向函数： forward_smt 换成 forward_dmt，多了"teacher.encoder 生成标准轨迹"和"rnn 自己滚动展开"两段循环。
  • 数据切分： get_smt_batch 换成 get_dmt_batch，序列总长度从 320 变成 576。
  • 超参数： batch 128 → 32，步数 150000 → 1500，学习率 3e-4 → 3e-5，调度从 warmup_constant 换成 warmup_cosine，各项损失系数也不同（见 2.4.1）。
  • 存档代码： 要删掉"把 teacher.decoder 拷贝给 rnn.decoder"的两行（见 2.4.5，这是重点）。

2.5.3 __init__：初始化

作用：和 SMT 的七件事相同，区别在于：创建模型后要加载 SMT 的权重，并且优化器里只放 rnn 的参数。

2.5.6 save_to_checkPoint：这里有一个必须改的地方

作用：保存完整断点到 checkpoint.pt，并单独存 rnn.pt、teacher.pt、logs.json。

为什么这两行在 DMT 里是个坑：

  • load_state_dict 是就地覆盖，直接改的是正在训练的 self.rnn.decoder，不是只改存档里的副本。
  • SMT 里 rnn.decoder 本来就不训练，拷贝一次让存档完整，没有副作用。
  • DMT 里 rnn.decoder 正在被训练。如果保留这两行，每次存档（每 300 步）都会把训练好的 rnn.decoder 和 to_logits 重置回 teacher 的版本，训练继续时从被覆盖的权重开始，最终存下的 rnn.pt 里的读出头也等于没训练。
  • 这个坑不会报错，只会表现为"白训练"：loss_readout 在每次存档之后会回到初始水平，整个读出头的训练等于每 300 步重来一次。我就是这样白训练了一天。

2.5.7 fw_bw_loss_calculation：前向与反向

作用：取一个 batch，前向算 loss，训练时反向传播；test 时只前向。和 SMT 相比，这里自己把一个 batch 切成几份做梯度累积，而不是多次从 Prefetcher 取数据。

与 SMT 版本的区别：

  • 加权方式： SMT 是每份损失除以累积步数，这里是乘以 n / total，样本数不均匀时也是正确的平均。(显存占用高，为了放进机器上训练才切割成小batch用累加的方式)
  • chunk 的限制： chunk(parts) 每份大小是 ceil(B / parts)，如果 batch 不能被整除，实际切出的份数可能少于 parts，这时 chunks[k][i] 会越界。当前 accumulate=1 没有这个问题，以后改大要注意。

2.5.8 forward_dmt：DMT 专属的前向

3. 测试结果

训练完成后，要测试作为最终产物的 rnn（rnn.encoder + rnn.decoder）。先看训练时的 loss 变化，再看评测结果。

3.1 训练 loss 曲线

SMT

SMT 在 20000 轮之前就进入逐步稳定的状态（总共训练 150000 轮）。

DMT

  • 一共训练 3000 轮，每轮约 14 秒，总计约 11.7 小时。
  • 大约 2500 轮时进入稳定收敛。
  • 原作者命令里是 1500 轮，我设成 3000 是因为当时是夜晚，不想中途醒来。

3.2 怎么评测语言模型

语言模型没法像分类模型那样有标准答案：同一个意思可以有很多种表达。所以这里主要看两类东西：

  • 指标：一步动力学 MSE、漂移曲线、逐位置下一字节 loss；
  • 生成效果：给一段开头，看模型续写得怎么样。

3.3 SMT 阶段的测试

结果

1. 一步动力学 MSE = 0.000454：rnn.encoder 学得很好。

  • 把 teacher.encoder 算出的真实记忆 \(Z_t\) 喂给 rnn.encoder 走一步，和 teacher.encoder 算出的 \(Z_{t+1}\) 比 MSE，即训练时 loss_rnn_enc 的测试集版本。
  • 无关样本之间的 MSE 基线是 1.7652，0.000454 比它小了三千多倍。

2. 漂移曲线：rnn 自己滚动，在 16 到 32 步之间彻底偏离。

  • 起点用 teacher 的记忆，之后 rnn 完全用自己的输出滚动，每隔 16 步和 teacher 同一时刻的记忆比一次 MSE。
  • step 16 时 MSE 是 0.29，到 step 32 就是 1.81，已经超过无关样本的基线 1.77，之后稳定在 1.93 附近。
  • 滚动一小段之后，rnn 的记忆就和真实状态完全脱钩了。单步误差很小，但每一步的输入都是上一步自己的输出，误差一步步累积放大，这正是 1.1 里说的"漂移"。

3. 逐位置下一字节 loss：读出头没问题，坏的是记忆。

  • 滚动到第 pos 步时，rnn.decoder 读 rnn 自己的记忆预测下一个字节；teacher 一侧用 teacher 自己的记忆读 teacher.decoder，作为对照。
  • pos 0 两边完全相同（0.5547），说明 rnn.decoder 确实是从 teacher.decoder 拷贝来的。
  • 之后 rnn 的 loss 一路变差：pos 16 是 2.10（teacher 0.40），pos 32 之后是 4.7 到 5.9，平均 4.23，teacher 平均 0.68。
  • 同一个读出头，读 teacher 的记忆表现很好，读 rnn 滚出来的记忆表现很差，所以问题完全出在记忆漂移上，不在 decoder。

4. 生成样本：teacher 通顺，rnn 很快变成乱码。

  • teacher 续写是通顺的英文，偶有拼写错误（dideals、snakens），在 temperature 0.8 下属于正常。
  • rnn 最初十几个字节还能接上，之后很快退化成字符乱码，和漂移曲线崩掉的时间点吻合。

SMT 阶段的结论： teacher 没有问题，rnn.encoder 的一步更新也学得很准，但 rnn 自己滚动十几步后就崩掉。这是 SMT 的预期缺陷，正是 DMT 要修的问题，所以它本身不算异常。

 

 

3.4 DMT 阶段的测试

结果（temperature 取值同上，原文未再说明，请确认）

逐项解读

  • 最直接的对比： SMT 的 rnn 在十几个字节之后就变成乱码，而 DMT 的 rnn 能把约 200 个字节全部写成可读的英文。这说明 DMT 确实修好了"自己滚动就崩"的问题。
  • 局部表现不错：
    • 单词的拼写和句式基本正确，一两句之内语法和语义说得通，比如样本 0 的 "Tony and Jane were very happy"、样本 4 的 "Soon, they got home and said goodby"；
    • 开头都能和提示接上，样本 4 的提示是 "Max and Lou laug"，续写 "hed and said"。
  • 越往后问题越多：
    • 逻辑断裂：样本 1 的 "the day animals of them was to take his surprise" 读不通；
    • 重复和拼写错误：record the pencil beautiful pencil、luckb、backpacket、Petert；
    • 人物名漂移：样本 3 中出现了提示里没有的 Mira，样本 1 里 Peter 变成了 Petert。
  • 这是小型字节级模型的典型表现： 局部词形和句式学得不错，但没有维持连贯情节的能力，只剩"看起来像儿童故事"的表面模式。teacher 自己的续写也是同样的水平（比如 "would whistle his toys and go under the big rocks"），所以不是 DMT 没训好，而是受限于 teacher 的能力上限。

3.5 小结

  • SMT 解决的是训练效率，但留下漂移问题： rnn.encoder 的一步更新很准（MSE 0.000454），但自己滚动 16 到 32 步之间，记忆就和 teacher 的记忆毫无关系，生成变成乱码。
  • DMT 修好了生成： 让 rnn 在自己展开出的记忆上向 teacher 轨迹对齐，rnn 可以稳定地连续生成约 200 个字节的可读文本。
  • 剩下的是模型能力问题： 语义连贯性不足，来自 teacher 本身的上限。要改善只能靠更大的模型或更长的训练。
